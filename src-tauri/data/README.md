# MAC manufacturer data

`mac-vendors.tsv` contains public IEEE Registration Authority assignments, bundled for offline lookup. The retrieval date is recorded in the file header. Data is generated by `scripts/update-mac-vendors.ps1`; do not hand-edit entries.

Sources:

- MA-L: https://standards-oui.ieee.org/oui/oui.csv
- MA-M: https://standards-oui.ieee.org/oui28/mam.csv
- MA-S: https://standards-oui.ieee.org/oui36/oui36.csv
- IAB: https://standards-oui.ieee.org/iab/iab.csv

The most specific assignment wins (36, 28, then 24 bits). A MAC assignment identifies the registered organization, which may be the network interface supplier rather than the device brand. Explicit device-reported manufacturer information takes precedence in the UI; its IEEE vendor remains available in the tooltip. Locally administered and multicast addresses do not receive a guessed vendor.
